# VR Player

Сборка через GitHub Actions: загрузите содержимое папки в репозиторий -> вкладка Actions -> Build APK -> Run workflow -> Artifacts -> VRPlayer-apk.
Либо Android Studio: File -> Open -> Build -> Build APK(s).

Управление: свайп - поворот, щипок - зум, двойной тап - сброс, тап - скрыть/показать панель.
